Making Local Deliveries Easier to Organise

Incomplete directions can cause delays and failed deliveries. This prototype helps organise recipient details, postcode information and useful location instructions in one place.

Project Overview

Project: Garun Mallam Smart Delivery

Sector: Delivery, logistics and local commerce

Initial target area: Garun Mallam, Kano State, Nigeria

Current stage: Early working prototype

Proposed next step: Explore integration with the official NIPOST Digital Postcode system, subject to developer access and API documentation.

Integration status: The official NIPOST API is not connected yet. This prototype does not verify postcodes or retrieve official address records.

Intended Impact

We aim to explore whether clearer delivery information and, if authorised, official postcode integration can help reduce address confusion and improve delivery coordination for local businesses.

These intended benefits still need to be tested with users.
